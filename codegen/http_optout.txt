#
# 判据(check_auth.py 用):一个 service 若一条 http 路由都没有,说明它整体不走 gateway
# (app/设备走 grpc 直连),不管;但**已经导出了一部分**却漏几条,那多半是加 rpc 时忘了配路由 ——
# hi.club.Agent.List 就是这么漏的,web 调 /api/v1/agent/list 拿到 code 5,由同事反馈才发现。
#
# 规则:新增 rpc 若落进这种缺口,要么配 http 路由,要么写进本文件(注明理由),否则 CI 失败。
